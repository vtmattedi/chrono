# Chrono web

The Chrono frontend (React 19, Vite, TypeScript, Tailwind 4, shadcn/ui). This app is part of the Chrono
monorepo; see the [root README](../../README.md) for what the project does, how it connects to
`apps/server`, and how to run and deploy it.

```
npm run dev      # from this folder, or `npm run dev:web` from the repo root
npm run build
```
